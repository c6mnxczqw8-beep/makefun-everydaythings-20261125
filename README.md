# Everyday Things, Two Lines, Longer Run — entry

A program/v1 entry for the make.fun "Everyday Things, Two
Lines" bounty. `main.py` writes a two-line entry to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The entry:

> A snooze button is a small loan you take from your future self, in units of nine minutes.
> The interest is paid in panic, and your future self never agreed to the terms.

Line one explains the thing by analogy; line two pays the
analogy's honest bill -- the interest, and the missing
consent, which a refinement pass made explicit. See
`CANDIDATES.md` for the full draft list this winner was
picked from.
